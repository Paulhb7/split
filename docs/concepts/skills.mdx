Split follows the open **[Agent Skills](https://agentskills.io) standard**
(Anthropic-originated, now cross-vendor): a skill is a **folder** — a required
`SKILL.md` (`name` + `description` frontmatter + instructions) plus optional
`scripts/`, `references/`, `assets/`. Agents load it by *progressive disclosure*
(name/description at startup → full `SKILL.md` on a match → bundled scripts on
demand). The same folder runs unchanged across Claude, Codex, Gemini, OpenCode,
Cursor, Vibe.

<Note>
This is the whole portability thesis — and it's a **standard, not a bet**.
</Note>

## Declared per-expert, mounted once

Skills are declared per-expert in `config/experts.json`
(`"skills": ["frontend-slides", …]`) and mounted **once** in the expert's
persistent workspace by `ensure_expert_workspace`, which symlinks each allowed
skill into every harness skill-dir (`.claude/skills/`, `.agents/skills/`,
`.vibe/skills/`).

The set is reconciled **idempotently** on every call:

- adding a skill to `experts.json` makes it appear on next launch,
- removing one unlinks it,
- a declared skill not yet vendored under `skills/<name>/` is silently skipped —
  so a persona may name a skill before it exists.

So `experts.json`'s `"skills": [...]` is the **filesystem filter**: the harness's
catalogue sees exactly the expert's allowed kit, nothing else.

## Vendored skills

Found in `config/skills/`, grouped by domain:

- **Documents / presentations:** `docx`, `frontend-slides`.
- **Design / frontend / dashboards:** `ui-ux-pro-max`, `dashboard`, `web-deploy`.
- **Research / literature:** `paper-search`, `paper-lookup`, `literature-review`,
  `scientific-brainstorming`, `hypothesis-generation`, `networkx`.
- **Finance / legal:** `market-data`, `model-audit`, `legal-templates`, `contract-review`.
- **Creative generation:** the `higgsfield-*` skills (`higgsfield-generate`,
  `-soul-id`, `-product-photoshoot`, `-marketplace-cards`) wrap the external
  `higgsfield` CLI — they need a **Higgsfield account** (`higgsfield auth login`),
  and some models require a paid plan.
- **Frontier science** (Curie's stack): `database-lookup`, `primekg`, `pytdc`,
  `biopython`, `diffdock`, `rdkit`, `medchem`, `esm`, `molecular-dynamics`,
  `scanpy`, `pymatgen`. REST/lookup skills run anywhere; the heavy-compute ones
  want Python deps and ideally a GPU.
- **Astronomy** (`nasa-api`, `astropy`, `astro-data`, `sky-viz`), **engineering**
  (`cad-design`), **sport** (`football-data`, `sports-news`, `sports-reporter`,
  `metadata`), **writing** (`prose-gen`), **coaching** (`coach-tracker`).

Many lookup skills accept an optional API key to raise rate limits
(`NASA_API_KEY`, `NCBI_API_KEY`, `FRED_API_KEY`, …); without one they fall back to
public/demo access. The `memory` skill (vault doctrine) is auto-mounted on every
expert.
