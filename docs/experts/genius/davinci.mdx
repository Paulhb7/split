<Info>**Genius** · creator · slug `genius_davinci`</Info>

You bring a reference image, a brief, or a site to redesign. DaVinci turns it
into a visual universe you couldn't build alone — its signature move is **a
single image → an explorable 3D scene**, alongside the rest of a design
practice: brand identities, UI mockups, static graphics, redesigns.

## What it delivers

Depending on the sub-role it picks for your brief:

- **Immersive scene** *(headline)* — a deployed Three.js viewer: a textured
  `.glb` model you orbit, a cinematic fly-through `.mp4`, and an ambient
  `.mp3` loop, all from one establishing image.
- **Brand identity** — a brand-kit folder: `logo.svg` (+ variants),
  `tokens.css`, an HTML brand guide (optionally PDF/`.docx`).
- **UI mockup** — a navigable multi-screen HTML prototype + a `design-spec.md`
  handoff doc.
- **Static graphic** — single-frame PNG/PDF at exact dimensions (poster,
  social, banner, print), multi-format when a campaign needs it.

## When to pick it

Pick **DaVinci** for visual creation that turns into something explorable or
brand-grade — 3D scenes, identities, mockups, graphics, redesigns. Pick
[Designer](/experts/super/designer) instead for a focused app/site mockup
without the generative-media stack, or [Engineer](/experts/super/engineer)
when a mockup needs to become real, shipped code.

## How to drive it

Start from an image or a brief:

```
Turn this image into a 3D scene
Create a full brand identity
Reimagine this visual universe
```

Attach a reference image (it becomes the establishing frame for a scene) or a
URL to redesign — it's read live and anchors the directions.

## What comes back

DaVinci announces a plan, then renders **3 moodboard directions** as live HTML
in the artifact pane; you pick one and it develops it into the full pack.
Everything lands on your Desktop by sub-role — `~/Documents/split-worlds/<slug>/`
(scenes), `split-brands/<brand>/`, `split-mockups/<project>/`,
`split-graphics/<project>/`. Anything share-ready can be published to a public
`*.surge.sh` URL on request.

## Prerequisites & limits

- **Higgsfield account required.** The `higgsfield-*` skills wrap the external
  `higgsfield` CLI — it must be on `$PATH` and signed in (`higgsfield auth login`),
  and all generations are billed to that account. Some models (e.g. Soul
  Character training) **require a paid plan** (Basic+); on a free plan DaVinci
  says so before submitting.
- **Scenes are explorable, not free-roam.** The signature scene is an orbitable
  textured model + a cinematic fly-through + sound — not a photoreal,
  walk-anywhere environment. If you need first-person free movement, DaVinci
  flags that as beyond the current generative stack and offers the
  fly-through + orbitable model as the closest approximation.
- **License safety.** Deliverables embed only imagery DaVinci generated or that
  is properly licensed — it never lifts a copyrighted image from a web result
  into your output.
