Why

A one-week, macro-balanced meal plan for lean recomposition — hold weight roughly steady while shifting body composition. High protein protects muscle; the calorie floor keeps it honest. This page is where the plan is followed, not just read.

Context

Target ~2,000 kcal/day, 160 g protein, Mediterranean pattern, 30-minute cooks. Seven days of breakfast / lunch / dinner / snack, each meal costed in kcal + macros. A generated shopping list covers the week.

How to use

Live in the Dashboard (bottom). Tick meals as you eat them — the kcal + macro tally fills against target. Log water, weigh in each morning, and file a weekly check-in. Everything saves on this device.

What I assumed

~78 kg starting point, no allergies, omnivore, one cook per meal, ≈ €65–75/week groceries. Steady-state calories (recomp, not a cut). Adjust the target in the check-in note if your numbers differ — this is a plan, not medical advice.
