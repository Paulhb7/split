04
Definitions — as settled in practice
04 / 13

What “agent” means now.

An agent is a model that directs its own process: it plans, calls tools, observes results, and loops — until the goal is met or it escalates to a human.

If the code path is fixed and the model merely fills in steps, practitioners call it a workflow, not an agent. That line — formalized by Anthropic in Building Effective Agents (Dec 2024) and adopted in OpenAI's builder guidance (2025) — is now the industry's working definition.

In 2026 usage, “an agent” means the whole running bundle — persona, tools, permissions, memory, and model — not the model alone. The same bundle increasingly runs on interchangeable engines; the model became a component, and the protocols on the right are what made the components snap together.

Modelthe engine
The reasoning core — Claude Opus 4.8, GPT-5.5, Gemini 3.1 Pro. Priced per token; refreshed roughly every six weeks in H1 2026.
Harnessthe runtime
The loop + tool wiring + permissions around the model: Claude Code, Codex CLI, OpenCode, Cursor. Where product value now lives.

Model Context Protocol — the USB port between agents and software. ~10,000 public servers, 97M monthly SDK downloads.
SurfaceACP
Agent Client Protocol — one wire between any agent and any editor or app. Adopted by JetBrains, Zed, Google, GitHub; 25+ agents.
FleetA2A
Agent2Agent (Linux Foundation) — how agents discover and task each other across vendors. 150+ member organizations.

Case study — the June 15 repricing

02 Jun

Anthropic announces metered agent credits

Agent SDK, headless, and third-party workloads leave the flat subscription pool: separate monthly credits — $20 Pro, $100 Max 5×, $200 Max 20× — billed at API list rates, no rollover.

16 Jun

…then pauses it within a day

After developer backlash, the change is suspended “for now”; a revised plan is promised with advance notice. Subscriptions keep covering agents — temporarily.

Signal

Flat-rate was priced for chat, not for loops

An agent that runs all night consumes what no $20 plan was built to fund. Whatever the final shape, all-you-can-eat agent pricing is ending across the industry.

Risks — what can break the thesis
11 / 13

Four ways this goes wrong.

01

The cull

Gartner: over 40% of agentic AI projects canceled by end-2027 — escalating cost, unclear business value, inadequate risk controls. Many use cases sold as “agentic” don't need agents; cost per task is volatile by design (retries, tool calls, reasoning steps).

Gartner press release, Jun 2025 · reaffirmed in 2026 Hype Cycle
02

Prompt injection

Still the #1 production failure mode in 2026 (OWASP). An agent that reads mail, browses, and holds credentials is one poisoned document away from acting for the attacker. No complete fix exists — only containment: least privilege, human gates on irreversible actions.

OWASP via Help Net Security, 11 Jun 2026
03

Weaponized agents

Sept 2025: a state-sponsored group hijacked a commercial coding agent to run espionage against ~30 targets — the AI executed 80–90% of the tactical work autonomously. Attacker productivity scales with yours; assume adversaries run agents too.

Anthropic disclosure, Nov 2025
04

Governance debt

Gartner's 2026 Hype Cycle puts agentic AI at the Peak of Inflated Expectations, with agent governance, security and FinOps still immature — and roughly a third of organizations reporting no formal plan for supervising agents they already run. Identity for non-human actors is the unsolved enterprise problem of 2026.
