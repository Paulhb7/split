About this Tonight's sky over Paris — computed in your browser the moment you opened this page. expand

Why. A sky briefing goes stale by morning, so this one refuses to be static: planet positions, rise/set times, the Moon's phase and the ranking of what's worth stepping outside for are all recomputed at load, for tonight, every time the file is opened. Built by Ride for the Split library as proof of the craft.

Context. Fixed to Paris (48.8566° N, 2.3522° E, Europe/Paris clock). Ephemerides run client-side on the astronomy-engine library; ISS passes are propagated with satellite.js from an embedded orbital-element snapshot — the one thing on this page that is not live, and it says so.

How to use it. Open it any evening. Read the one thing, skim the ranking, check the horizon strip for 23:00, and if an ISS pass is marked visible, be outside two minutes early. Reload = recompute.

What I assumed. Naked eye and binoculars, no telescope; a city horizon (rooftops eat the first ~5–10°); "tonight" runs noon-to-noon so the page still shows the ongoing night after midnight. Needs the network once, for two open-source libraries and the typeface.

Method

  • Planet & Moon positions, rise/set, phase, magnitudes: astronomy-engine v2.1.19 (Don Cross, MIT) — VSOP87-class accuracy, computed at page load with refraction. Twilight depths (−6°, −18°) use the airless geometric Sun altitude, as their definitions require.
  • ISS: SGP4 propagation via satellite.js v5 from the embedded CelesTrak element set. Shadow test uses a cylindrical umbra; a pass is "visible" when the station is sunlit while your sky is darker than −6° Sun altitude.
  • Bright-star positions on the chart come from a fixed catalogue embedded in the page (they do not change on human timescales).

Sources & cross-checks

  • ISS elements: CelesTrak GP data, NORAD 25544 — epoch on the pass table above.
  • Cross-check rise/set & visibility: timeanddate.com — night sky, Paris.
  • Cross-check ISS passes: heavens-above.com.
