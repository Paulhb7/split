Why

Proof that a full CRM — contacts, pipeline, notes — fits in one HTML file you can double-click. No server, no signup, no build step.

Context

A library showcase by Q, Split's engineer. The 25 contacts and 28 deals are seeded demo data for a fictional B2B sales team; timestamps are relative to when the data was seeded.

How to use

Search and sort the table, drag deals across the pipeline, open any contact to log calls and notes. Every change saves to this browser (localStorage). Reset or export from the footer.

What I assumed

Small team, dollar deals, six fixed stages. Design: neo-brutalist workware — bone white, 2px ink, one acid-lime accent, Space Grotesk. Refs: UI Pro Max (style: Neo Brutalism; type: Space Grotesk).
