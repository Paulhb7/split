# Clause review checklist

The clauses to sweep for, what to check, and the typical 🔴 trap. Read
*to the boss's side* — the same clause favours one party and exposes the
other. Skip clauses the document type doesn't have; flag the ones it
*should* have and doesn't (the "missing clauses" section of the review).

Bilingual: FR term // EN term. Reply in the user's language.

| Clause (FR // EN)                                   | Check                                                                                   | Typical 🔴 trap |
| --------------------------------------------------- | --------------------------------------------------------------------------------------- | --------------- |
| Responsabilité // Limitation of liability           | Is there a cap? Mutual? What's carved out (IP, confidentiality, data breach)?            | Uncapped / unlimited liability, or cap only protects the *other* side |
| Indemnisation // Indemnification                    | Mutual or one-way? IP indemnity present? Caps and procedure?                            | One-way indemnity running against the boss |
| Propriété intellectuelle // IP ownership            | Who owns deliverables? Is *pre-existing* / background IP protected? Licence-back?        | Full assignment sweeping in the boss's prior work / tools |
| Confidentialité // Confidentiality                  | Mutual? Term? Carve-outs (public, independently developed, compelled disclosure)?        | One-way, perpetual, or no standard carve-outs |
| Durée & résiliation // Term & termination           | Notice period? Termination for convenience? For cause? Survival clauses?                 | Locked in with no exit / only the other side can terminate |
| Renouvellement automatique // Auto-renewal          | Renewal term + cancel window. (FR: Loi Chatel notice duties for consumers.)              | Silent auto-renew with a narrow / past cancel window |
| Données personnelles // Data protection             | Personal data in scope? DPA / addendum present? Transfers (SCCs)? (FR/EU: RGPD.)         | Personal data processed with no DPA / no transfer mechanism |
| Non-concurrence // Non-compete                      | (FR: must be limited in time + space AND financially compensated, or void.) Scope reasonable? | Unpaid / unbounded non-compete (void in FR; risky in US) |
| Non-sollicitation // Non-solicitation               | Scope, duration, employees vs clients.                                                  | Overbroad, indefinite |
| Paiement // Payment terms                           | Amount, schedule, late fees/interest, who bears taxes/expenses.                          | Penalties only on the boss; vague "additional fees" |
| Garanties // Warranties & representations           | What's promised? Disclaimers ("as-is")? Remedies for breach?                            | Broad warranties given by the boss / all warranties disclaimed *to* the boss |
| Droit applicable & juridiction // Governing law & venue | Which law? Which court / arbitration? Convenient or hostile forum?                  | Foreign / hostile forum, mandatory arbitration waiving rights |
| Force majeure                                       | Balanced? Does it cover the boss's likely disruptions?                                   | One-sided — only excuses the counterparty |
| Cession // Assignment                               | Can either side assign? Consent required? Change-of-control trigger?                     | Counterparty can freely assign; boss cannot |
| Modification // Amendment                           | Written + signed only? Unilateral change rights?                                         | Counterparty can change terms unilaterally (common in ToS) |
| Indemnité de rupture // Termination fees / penalties | Triggers and amounts.                                                                    | Disproportionate exit penalty on the boss |
| Acceptation / recette // Acceptance (services)      | Acceptance criteria + cure period for deliverables.                                      | Payment due regardless of acceptance |

## Severity quick rule

- **🔴 Blocker** — uncapped liability against the boss · full IP assignment of pre-existing work · one-way indemnity · no termination right · unpaid/unbounded non-compete (FR) · personal data with no RGPD/DPA basis · illegal or unenforceable term.
- **🟡 Negotiate** — worse than market or worse than the house playbook, but survivable: asymmetric notice, narrow cancel window, missing liability cap, hostile-ish forum.
- **🟢 Acceptable** — standard, mutual, fair. Mention only on a full-sweep request.
