Reliefs.

Câblage — une ligne par thème

/* app.css — la forme s'ajoute en tête de la pile,
   aucun DOM ni JS en plus : */
.app.theme-gatsby {
  background:
    url(/bg3d/gatsby-sunburst.webp)
      no-repeat 100% 0 / 250px auto,
    radial-gradient(820px 520px at 86% -12%,
      rgba(212,175,55,.22), transparent 60%),
    linear-gradient(180deg, #0a0a0a, #050505);
}
  • WebP alpha 50–100 Ko par forme — rendu Blender/Spline ou génération IA, pas de three.js : la bar est always-on-top, un WebGL permanent coûte en batterie.
  • Opacité cuite dans l'asset : 6–20 % sur les thèmes sombres, 30–70 % en tonal sur les clairs (Baroque, Ghibli).
  • Dérive lente optionnelle — background-position animé sur 60 s ; jamais de rotation temps réel.
  • Fondu radial côté contenu si la forme approche du texte (mask dans l'asset, pas en CSS).
  • Bright et Classic restent les plus discrets — verre tonal côté clair, cuivre à α 0.12 côté sombre : l'objet est à peine là, la sobriété reste le thème.
  • Minuit s'allume seul — au boot puis re-check chaque heure : getHours() ∈ [21, 7) bascule le skin sur minuit ; un pick manuel (persisté dans split.skin) gagne toujours. Une seule règle JS dans skins.ts, zéro dépendance.
